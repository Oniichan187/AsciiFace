# AsciiFace

## Usage

Open `index.html` in Chrome or Edge and allow camera access.

- Pick a camera from the dropdown. The ASCII render appears next to it.
- **Color** tints every character with the color of the pixels under it.
- Choose a charset, set 40–320 columns and the font size, and adjust brightness, contrast, gamma, invert and mirror.
- **Copy text** copies the current frame as plain ASCII. **Save PNG** saves it as an image.

Everything runs locally in the browser.
